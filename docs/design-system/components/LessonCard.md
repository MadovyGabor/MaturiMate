# LessonCard

A lesson or practice unit in a topic list: type, estimated time, title, short description and a topic tag.

- **The caller provides:** type and time (`label-small`), title (`headline-small`), description (`body-medium`, `on-surface-variant`), tag and the open handler.
- `surface-container-low` background, `radius-lg` corners, `space-4` padding. A shadow only if the card floats.
- The whole card is clickable; the text button only repeats that.
